Alom Student Flutter app. Configure API_BASE_URL with --dart-define and run flutter pub get / flutter run. Current client flows: login/session restore, public course catalogue, enrolled course summary, notices, logout and QR attendance submission. QR check-in is processed by the LMS attendance controller, authoritative for expiry, replay, roster membership, branch scope and optional GPS requirements. Wishlist, support tickets, cart/checkout, invoices, lesson progress, assignments, exam attempts, reviews and question-set attempts remain tracked in docs/FINAL-LMS-FEATURE-PARITY-TRACKER.md; do not enable those screens until matching server APIs and acceptance tests exist.
